# betaflight-designer-fonts

Якщо коротко, це зібрані в одному місці оригінальні шрифти з ПЗ Betaflight, нарізані та конвертовані в пнг (а ще зкомпілені в otf) для зручності використання в дизайні та монтажі відео.
